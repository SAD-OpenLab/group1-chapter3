# 我的Git学习笔记
##第一次Git实验总结
1.git add 的作用是：
将工作区修改后的文件添加到暂存区 (stage)，标记这些改动准备提交，并不会真正生成版本记录。
2.git commit 的作用是：
把暂存区里已经 add 的改动，保存到本地 Git 仓库，生成一条带提交信息的版本快照，只作用在本机，不会上传到网上。
3.git restore notes.md 的作用是：
丢弃工作区对 notes.md 的修改，把文件恢复成暂存区的状态；如果暂存区没有改动，则恢复成本地仓库里最近一次提交的版本，撤销还没 add 的修改。
4.commit 与 push 的区别是：
commit：仅在本地生成版本快照，改动保存在自己电脑的本地仓库，远端 GitHub 仓库看不到。
push：把本地已经 commit 完成的版本，上传推送到远程 GitHub 仓库，让远端服务器同步你的提交，其他人可以看到。
